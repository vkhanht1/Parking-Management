# Smart Edge-AI Parking Management System (MVP)

Core MVP implementation using Ultralytics YOLOv8 and OpenCV for real-time parking slot occupancy detection.

## Tech Stack
- Python 3.13
- Ultralytics YOLOv8
- OpenCV & NumPy

## How to Run
1. Install dependencies: `pip install -r requirements.txt`
2. Run the main script: `python main.py`
